# Лабораторная работа № В-1

Состав:
- `index.php` — главная страница;
- `menu.php` — меню и подменю;
- `viewer.php` — вывод записей с пагинацией;
- `add.php` — добавление записи;
- `edit.php` — редактирование записи;
- `delete.php` — удаление записи;
- `style.css` — оформление;
- `friends.sql` — создание базы и таблицы.

## Как запустить
1. Создать базу `friends` и выполнить `friends.sql`.
2. В `index.php` при необходимости изменить параметры подключения к MySQL:
   - хост;
   - пользователь;
   - пароль.
3. Разместить файлы на сервере с PHP и MySQL.
4. Открыть `index.php` в браузере.

## Поля записи
- фамилия;
- имя;
- отчество;
- пол;
- дата рождения;
- телефон;
- адрес;
- e-mail;
- комментарий.
